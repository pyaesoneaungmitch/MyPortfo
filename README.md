# Pyae Sone Aung (Mitch) Portfolio

This repository contains the source code for my personal portfolio website.

The portfolio was created to give recruiters and hiring teams a clear place to review who I am, what I have built, and how to contact me for graduate software development opportunities.

## Live Portfolio

https://pyaesoneaungmitch.github.io/MyPortfo/

## What The Portfolio Includes

- A short professional introduction and graduate software developer profile
- Selected full-stack, web and applied-AI projects
- Project screenshots, posters and demo videos where available
- CV access for applications and recruiter review
- Contact links, including GitHub, LinkedIn, email and phone
- A small personal section to show personality beyond technical work

## Why This Repository Exists

This repository supports my public portfolio website for CVs, LinkedIn and job applications.

It is not intended to be a reusable template, tutorial project or downloadable starter app. The source is kept here so the portfolio can be maintained, versioned and deployed professionally through GitHub Pages.

## Deployment

The portfolio is deployed from the `main` branch using GitHub Actions and GitHub Pages.
